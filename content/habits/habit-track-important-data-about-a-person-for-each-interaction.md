# Habit - Track important data about a person for each interaction

Being able to track important data about someone will make it easier to know what to talk for the next time you talk and actively fuel the relationship. We don't need to create flashcards, but we should note them down.

For example, if someone's birthday is coming up, then send a card to their home. [[habit-make-interpersonal-interactions-more-personal]].

## [[cue-in-terms-of-habits|Cues]]

- After an [[interpersonal-interaction]] with someone.

## [[response-in-terms-of-habits|Responses]]

- On each interaction, track the following:
  - Important topics and conversations (via text or in person).
  - Date of last interaction.
  - Important milestones.
  - Birthdays.
  - Names of children and pets.

## [[reward-in-terms-of-habits|Rewards]]

- Increased ease in keeping up with the person.
- Happiness for remembering details.
