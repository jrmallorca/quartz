# Habit - Check avocado ripeness

## [[cue-in-terms-of-habits|Cues]]

- Getting avocados in a store.
- Checking if an avocado is ready for consumption.

## [[response-in-terms-of-habits|Responses]]

- Check if the colour of the avocado's skin is a very dark green.
- Check if the avocado can be gently squeezed and bounced back.
  - If it can't be squeezed, it is not ripe yet.
  - If it's too squishy, it is overripe.

## [[reward-in-terms-of-habits|Rewards]]

- Avocados for consumption.
