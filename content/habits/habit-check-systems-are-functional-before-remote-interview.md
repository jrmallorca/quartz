# Habit - Check systems are functional before remote interview

## [[cue-in-terms-of-habits|Cues]]

Before the start of a remote interview.

## [[response-in-terms-of-habits|Responses]]

- Check the camera is working.
- Check the audio is working.
- Check the microphone is working.
- Check any screen sharing is visible by everyone.
- Check with the interviewer that they're able to hear you.
