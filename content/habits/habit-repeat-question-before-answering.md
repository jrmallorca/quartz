# Habit - Repeat question before answering

## [[cue-in-terms-of-habits|Cues]]

- After [[habit-pause-after-being-asked-a-question]].
- Before answering a question.

## [[response-in-terms-of-habits|Responses]]

Vocally repeat the question slowly. The question can be repeated as it's whole original version, partial original version, or reworded.

### Concrete example

Q: "How do you fix this problem?"

Pause for 3 - 5 seconds. 

A: "How do I fix this problem..." or
A: "To fix this problem..." or
A: "Fixing this problem would mean..."
