# Memory palaces for temporary storage should be minimally actively recalled

As [[memory-palaces-require-active-recall-to-be-moved-into-long-term-memory]], [[memory-palace]]s that are used for temporary storage of information should have a minimal amount of [[active-recall]] sessions.

Information that is likely to be temporarily stored are:
- Shopping lists
