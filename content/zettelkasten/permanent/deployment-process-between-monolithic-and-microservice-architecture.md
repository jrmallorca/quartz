# Deployment process between monolithic and microservice architecture

Deploying [[monolithic-architecture]] is more straightforward as it only requires deploying one codebase and its required dependencies in a single environment.

For [[microservice-architecture]], every microservice is independently deployable and likely have to be [[containerised-applications]].
