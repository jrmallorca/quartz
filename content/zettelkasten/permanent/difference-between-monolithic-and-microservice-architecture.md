# Difference between monolithic and microservice architecture

[[monolithic-architecture]] structures a system as a collection of tightly-coupled features within a single codebase.

[[microservice-architecture]] structures a system as a collection of multiple, independently deployable, and loosely coupled services that focus on 1 feature each.
