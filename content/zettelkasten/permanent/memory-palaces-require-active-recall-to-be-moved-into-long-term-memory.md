# Memory palaces require active recall to be moved into long term memory

[[memory-palace]]s are powerful **short-term** memory tools. They need [[active-recall]] to be moved into long-term memory.

As [[spaced-repetition-reduces-exponential-decay-of-retained-information]], using [[spaced-repetition]] in the following way will retain the information into our long-term memory:

- Go through the memory palace from start to end 3 times.
- On the next active recall session, go through the memory palace from end to start 3 times.
- On the next active recall session, go through the memory palace from middle to start 3 times.
- On the next active recall session, go through the memory palace from middle to end 3 times.
- On the next active recall session, go through a random route through the memory palace 3 times.
