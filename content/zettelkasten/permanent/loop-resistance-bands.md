# Loop resistance bands

Loop resistance bands have the following properties:

- 41 inches/104cm.
- Continuous loop.
- Flat shape (various sizes should have the same thickness).
- Variable widths to determine difficulty of resistance bands.
- Multi-layered (if they're good quality).
