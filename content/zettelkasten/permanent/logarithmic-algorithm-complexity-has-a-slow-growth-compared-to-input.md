# Logarithmic algorithm complexities have a slow growth compared to input

[[logarithm]] [[algorithm-complexity]] grow slowly in time taken compared to input. This is because for each step in a loop, input is halved as [[logarithmic-algorithm-complexities-are-always-assumed-to-be-base-2]], and therefore drastically reduces the amount of steps required to finish an algorithm
