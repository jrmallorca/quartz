# Difference between class and object in OOP

A class is like a blueprint: we define the characteristics of what we're making (fields) and we define what it can do (methods).

An object is an instance of the class.

## Analogy

Imagine how we can create a robot. We create a blueprint (class) to understand what the robot's characteristics and functions are. For example. it has red eyes and can walk.

From the blueprint, we can create the robot and turn it into an instance. It's not limited to just one instance, we can create multiple robots of the same type.
