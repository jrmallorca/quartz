# Reward Prediction Error (RPE)

Reward Prediction Error (RPE) refers to the difference between the expected [[reward-in-terms-of-habits]] and actual [[reward-in-terms-of-habits]] received from performance of action(s).

There are 3 types of prediction errors:

- [[positive-reward-prediction-error]]
- [[negative-reward-prediction-error]]
- [[zero-reward-prediction-error]]
