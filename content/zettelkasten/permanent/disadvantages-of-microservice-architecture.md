# Disadvantages of microservice architecture

- Initial development of a system with [[microservice-architecture]] will require more team coordination to understand how each service would communicate to each other.
- Deployment is less straightforward as there are multiple microservices to deploy and likely have to be [[containerised-applications]].
- Tracing movement of code for debugging across multiple services will be more complex and require more team coordination.
