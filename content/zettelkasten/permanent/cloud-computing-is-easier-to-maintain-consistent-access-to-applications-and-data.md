# Cloud computing is easier to maintain consistent access to applications and data

[[cloud-computing]] can make it easier to maintain consistent access to applications and data as [[cloud-providers-can-guarantee-a-certain-level-of-availability]] and will be responsible for minimising [[common-issues-of-losing-application-and-data-availability]].

However, [[cloud-providers-only-guarantee-availability-for-systems-they-cover]].
