# Requirements on Merino Wool Garments

- [ ] <20 microns as [[merino-wool-that-are-less-than-20-microns-are-not-itchy]]
- [ ] \>70% wool, if blended
- [ ] Not blended with polyester as [[merino-wool-blends-with-polyester-have-significantly-reduced-odour-reduction]]
