# Big O

Big O refers to the worst-case [[algorithm-complexity]], based on input, in terms of either time or space.

How severe is the growth of complexity of an algorithm when given an input? How much more severe would it be if the input is increased?

Examples:

- O(1): For every input, there is no change in complexity. This is the most ideal complexity.
- O(n): For every input, complexity grows linearly.
    - For a loop, each increase in input will increase the amount of loops to process the input.
- O(n^2): For every input, complexity grows exponentially.
