# Using sunscreen properly inhibits vitamin D production

According to [this article](https://www.medicalnewstoday.com/articles/317278#Sunscreen-may-reduce-vitamin-D-3-production-by-99-percent), if the proper amount of sunscreen is used, the body's vitamin D production may be inhibited by 99%.
