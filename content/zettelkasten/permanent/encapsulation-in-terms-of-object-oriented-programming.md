# Encapsulation, in terms of object oriented programming

Encapsulation refers to wrapping data and any functions that work with that data into one unit. This would be a class in Java.

Encapsulation allows for [[data-hiding-in-terms-of-object-oriented-programming]], but is more focused on hiding the complexity of a class rather than protecting its data.
