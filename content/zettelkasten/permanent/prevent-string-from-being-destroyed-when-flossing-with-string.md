# Prevent string from being destroyed when flossing with string

Due to the [[gap-lengths-between-teeth]], prevent string from being destroyed when flossing with string by [[exit-through-the-gap-when-flossing-teeth-with-string]] and [[do-not-exit-upwards-when-flossing-teeth-with-string]].
