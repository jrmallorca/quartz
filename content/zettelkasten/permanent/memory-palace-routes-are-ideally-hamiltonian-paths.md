# Memory palace routes are ideally Hamiltonian paths

As [[memory-palaces-are-made-of-a-sequence-of-loci]], the routes in a [[memory-palace]] should resemble a [[hamiltonian-path]], i.e., no loci (vertex) should be visited more than once.

This will reduce confusion or cognitive load of remembering the order of the information.
