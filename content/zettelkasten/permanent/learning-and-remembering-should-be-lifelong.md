# Learning and remembering should be lifelong

Learning and remembering should be lifelong. [[learning-requires-memory]] and [[quality-of-performance-can-plateau-or-decrease-without-nurture]]. If both learning and remembering are nurtured as a [[habit]], then learning efficiency and memory retention will increase while anything learned will be an advantage later in life.
