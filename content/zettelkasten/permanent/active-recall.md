# Active recall

Active recall is a study technique of actively retrieving information to test and improve memory retention.

This is different from recognition of an answer. For example, multiple test questions aren't effective for studying as learners can recognise the answer through familiarity and passive recall.

## Concrete example

- Questions in a test that require you to explain your understanding.
- If you were asked "What is the capital city of Wales?" without hints or searching up the answer through an external source.
