# AWS Lambda workflow

The [[aws-lambda]] workflow are the 4 steps below:

1. Upload code to the [[aws-lambda]].
2. Set code to trigger from an event source.
    - These event sources could be other [[amazon-web-services]], mobile applications or HTTP endpoints.
3. [[aws-lambda]] runs the code when triggered.
4. [[aws-lambda-follows-consumption-based-model]] and gets paid only when run.
