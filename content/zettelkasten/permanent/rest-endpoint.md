# REST endpoint

A [[rest-api]] endpoint is a [[uniform-resource-locator-url]] or [[uniform-resource-identifier-uri]] that represents a resource in a [[rest-api]] [[client-server-architecture]].

For example, consider a simple [[rest-api]] for managing a collection of books. The following are example REST endpoints that follow [[http-request-methods]]:

- GET /books: Retrieve a list of all books.
- GET /books/{id}: Retrieve details of a specific book with the given ID.
- POST /books: Create a new book.
- PUT /books/{id}: Update the details of a specific book.
- DELETE /books/{id}: Delete a specific book.
