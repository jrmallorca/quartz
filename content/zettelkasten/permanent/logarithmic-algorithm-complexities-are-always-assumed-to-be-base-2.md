# Logarithmic algorithm complexities are always assumed to be base 2

A [[logarithm]] [[algorithm-complexity]] is always assumed to be base 2. This is because operations usually operate in base 2 and will be dropped, as seen when we [[remove-constants-when-considering-algorithm-complexity]].

[[logarithm]] [[algorithm-complexity]] can look like O(log(n)).
