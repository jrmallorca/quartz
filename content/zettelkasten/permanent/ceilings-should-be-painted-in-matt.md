# Ceilings should be painted in matt

When [[painting-ceilings]], matt paint should be used as it will hide imperfections and ceilings requires less durability as there is little to no interaction with it. Ceilings will have lights involved, or will reflect any ambient lighting, which will attract the eye upwards. This is undesirable.
