# Snowball effect

The snowball effect is a phenomenon where something (e.g., motivation, a rumour, [[compound-interest]], etc.) initially starts off small but gradually grows larger and more significant.

It is comparable to a small snowball rolling downhill and gradually getting bigger in size as it picks up more snow.
