# Do not exit upwards when flossing teeth with string

According to [[prevent-debris-from-getting-stuck-when-flossing-with-string]] and [[prevent-string-from-being-destroyed-when-flossing-with-string]], exiting upwards would remove debris between the teeth LESS effectively.
