# Development process between monolithic and microservice architectures

As a [[monolithic-architecture]] uses a single codebase, it is much easier to start and add more features as you go. However, it will get increasingly more complex to maintain.

As a [[microservice-architecture]] utilises multiple services that must communicate with each other, planning and coordination is required from the start. However, finding bugs and making changes will be easier as each service only focuses on a single feature.
