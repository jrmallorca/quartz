# Boot to console instead of GUI from GRUB

1. Turn on the computer to Linux.
2. On the GRUB screen, press "e".
3. Navigate to the line that starts with "linux", and also has "vmlinuz" on the line, using arrow keys.
4. Go to the end of the line, add a "space" followed by a "3".
5. Press "Ctrl + x" or "F10" to boot to console mode.
