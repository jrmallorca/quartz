# Confidence can be based on a foundation of known performance from previous tests, especially when repeated

Confidence can be based on a foundation of repeated performance. This can be proven through frequent and low-stakes testing as it constantly demonstrates our performance against simulations of the real world. For each test, we come to understand our current capabilities and how to improve it.

## Concrete example

Remember the numerous mock tests we used to do before each actual test for GCSEs and A levels. For each repetition of a test, we became more confident on our performance for the actual test.
