# Zero Reward Prediction Error (RPE)

A zero [[reward-prediction-error-rpe]] occurs when the actual [[reward-in-terms-of-habits]] is equal to the expected [[reward-in-terms-of-habits]].

This signals that the situation is as anticipated, keeping the same motivation to perform the behaviour next time.
