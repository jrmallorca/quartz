# Active recall should follow a spaced repetition algorithm

[[active-recall]] should be scheduled under a [[spaced-repetition]] algorithm due to the following:

- [[frequent-and-low-stakes-testing-reduces-test-anxiety-through-familiarity-and-spread-consequences]]
- [[spaced-repetition-reduces-exponential-decay-of-retained-information]]

There should be enough time in between such that a little forgetting has happened to introduce [[desirable-difficulty-in-learning]] but not enough that it requires relearning the material.

## Concrete example

Anki is an application that follows its own [[spaced-repetition]] algorithm to determine when to review certain flashcards.
