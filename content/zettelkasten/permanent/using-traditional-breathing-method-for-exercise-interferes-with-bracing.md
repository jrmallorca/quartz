# Using traditional breathing method for exercise interferes with bracing

Using the [[traditional-breathing-method-when-exercising]] will interfere with [[brace-the-core-when-exercising]]. This breathing method, when exhaling, releases the tension built in your core and therefore removes the strength from the tension.
