# Elaborative encoding

Elaborative encoding are mnemonic systems that attaches metadata to information we want to memorise. The metadata is used for better retention and future recall of the information.

Examples of these mnemonic systems are:

- [[memory-palace]]
- Alphabet (peg) system
- Number system (e.g., Person-Action-Object or Major system)
