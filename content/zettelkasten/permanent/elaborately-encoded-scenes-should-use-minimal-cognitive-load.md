# Elaborately encoded scenes should use minimal cognitive load

The creation of scenes through [[elaborative-encoding]] should have as minimal cognitive load used as possible.

This can be done by using knowledge/resources that we already know to create an scene. [[cognitive-load-from-elaborative-encoding-is-indirectly-correlated-to-quantity-of-information-in-memory]]. Examples of information we know:

- Pop culture references
- Cartoons
- Anime
- Mythology
- etc.

To see this in action, consider memorising the word "garrison". To me, I could imagine Gary, from Spongebob, giving birth to a son. This produces an image of "Gary's son", which is very similar to "garrison".

Someone else may use different images from the knowledge they have to memorise "garrison".
