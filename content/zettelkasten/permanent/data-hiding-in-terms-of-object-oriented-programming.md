# Data hiding in terms of object-oriented programming

Data hiding refers to restricting the access to class fields. This protects data in fields from any unauthorised or unexpected edits.

In Java, this would refer to choosing the access of a class field of `private`, instead of `public`, to prevent any unauthorised access from the outside.
