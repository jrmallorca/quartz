# Mistakes in remembering within memory palaces should be reflected upon

When a mistake is made when remembering something within the [[memory palace]], reflect upon the following questions:

- How could you modify the image to be more memorable?
- Is the placement wrong?
    - For example, should you place a white pen on a white table where it's likely to be disguised?
