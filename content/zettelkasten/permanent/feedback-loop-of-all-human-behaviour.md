# Feedback loop of all human behaviour

The feedback loop behind all human behaviour is simplified from [[reinforcement-learning-in-animals]]:

1. try,
2. fail,
3. learn,
4. try differently.

With this feedback loop, [[habit-formation-naturally-optimises-behaviour]].
