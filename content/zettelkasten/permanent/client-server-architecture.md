# Client-server architecture

Client-server architecture is a network-based computing structure that allows different applications to exchange data and communicate over a network.

The client is the application that requests services from the server, such as retrieving or storing data, performing calculations, or executing commands. A client could be the following:
- An application that requests for weather data.
- A website that requests for the latest news.

The server is the application that provides services to the client, such as processing requests, sending responses, or completing actions. A server could be the following:
- [[virtual-machine]].
- [[amazon-elastic-compute-cloud-ec2]].
- On-premises computer.
