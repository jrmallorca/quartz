# Import duty to UK

According to [GOV.uk](https://www.gov.uk/import-goods-into-uk), import items with **tariff preference** will have no extra import duties.

You can look at the [commodity codes](https://www.trade-tariff.service.gov.uk/find_commodity) to know if the items you want from which country will have import duty.

You only need to be concerned about import duty if your shopping is [equal or over £135](https://www.gov.uk/goods-sent-from-abroad/tax-and-duty).
