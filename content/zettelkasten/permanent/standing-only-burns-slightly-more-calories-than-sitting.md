# Standing only burns slightly more calories than sitting

In a study with 74 healthy people, it was discovered that standing only burns slightly more calories than sitting.

With the [[difference-of-calories-burned-between-sitting-standing-and-walking]], sitting burned 80 calories/hour while standng burned 88 calories/hour.

There is only an 8 calorie/hour difference in calories burned.
