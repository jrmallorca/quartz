# Difference between interleaved and varied practice

The difference between [[interleaved-practice]] and [[varied-practice]] is that the 1st one practices multiple different topics in a random order while the 2nd one practices the same problem in different contexts or perspectives.

## Analogy

## Concrete example

For interleaved practice, a mathematics student might practice addition, subtraction, multiplication, and division problems all within the same session and randomising the problems encountered, rather than practising only addition problems for a set period, then moving on to subtraction, and so on.

For varied practice, imagine solving an anagram such as "tmoce" into "comet". Varied practice would involve solving the same problem in different contexts (e.g., "cetom" still becomes "comet").
