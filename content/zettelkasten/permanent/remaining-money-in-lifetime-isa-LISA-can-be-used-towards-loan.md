# Remaining money in Lifetime ISA (LISA) can be used towards loan

After using the deposit for a mortgage, any remaining money in a [[lifetime-isa]], can be transferred to the mortgage.

This is useful if you don't plan on using the [[lifetime-isa-as-an-alternative-retirement-fund]] as [[withdrawals-from-the-lifetime-isa-incur-a-25-percent-penalty-if-not-used-for-its-designed-purposes]].
