# Implementation intention

An implementation intention is a plan of when and where to act. It creates a [[response-in-terms-of-habits]] through a single or multiple [[cue-in-terms-of-habits]].

Primarily, it is used to form [[habit]]s, whether they are [[outcome-based-habits]] or [[identity-based-habits]], or to achieve a goal.

An implementation intention follows an if-then process such that given a set of conditions, fulfill the required goal. As [[time-and-location-are-the-2-most-common-cues]], consider the following example:

> I will <BEHAVIOR> at <TIME> in <LOCATION>.
