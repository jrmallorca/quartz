# Network outages can cause a lack of availability

Applications will usually require some network connectivity. These are [[examples-of-applications-reliant-on-network-connectivity]].

If any example of these network connections fail, it will cause a lack of availability.

This could be relieved by using [[cloud-computing]] as [[cloud-providers-can-guarantee-a-certain-level-of-availability]]. However, [[cloud-providers-only-guarantee-availability-for-systems-they-cover]].
