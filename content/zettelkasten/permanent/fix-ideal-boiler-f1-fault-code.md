# Fix Ideal boiler F1 fault code

To fix the [[ideal-boiler-f1-fault-code|Ideal boiler F1 fault code]]:

1. Turn all dials off by rotating them counter-clockwise.
2. Find the 2 blue valves underneath the boiler, at the right side. This is the filling loop.
3. Close the one furthest to the back by rotating it ~90° clockwise.
4. SLOWLY open the one furthest to the right by rotating it counter-clockwise to increase the pressure.
5. Once the [[ideal-boiler-pressure-should-ideally-be-1-5-when-the-boiler-is-cold|pressure has reached between 1 and 1.5]], then close the right-most valve and open the back-most valve.
6. Restart the boiler, like a car, by turning the right-most dial fully clockwise for a second then putting it back to one of the options.
7. Put all dials back to their previous state.
