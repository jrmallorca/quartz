# Advantages of monolithic architecture

- Initial development of a system with [[monolithic-architecture]] is easier as all features would be contained in 1 codebase.
- Deployment is straightforward as there is 1 service to deploy.
- Tracing movement of code for debugging across multiple features will be easier due to its tightly-coupled nature.
