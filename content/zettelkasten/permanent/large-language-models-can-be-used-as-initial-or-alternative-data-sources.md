# Large Language Models (LLMs) can be used as initial or alternative data sources

[[large-language-models]] can be used as initial or alternative data sources, instead of relying on search engines like Google or DuckDuckGo. However, [[large-language-models-are-not-always-trustworthy]] in the information that they provide.

They can be useful in forming a summary of the information you want or have, asking for more information, etc. This can be achieved through [[prompt-engineering]].
