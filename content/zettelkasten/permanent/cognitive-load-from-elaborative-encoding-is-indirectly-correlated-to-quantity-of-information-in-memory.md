# Cognitive load from elaborative encoding is indirectly correlated to quantity of knowledge in memory

The cognitive load required for [[elaborative-encoding]] is indirectly correlated by the quantity of knowledge we have in memory.

I.e., the more references we can use from our knowledge, the easier it is to combine them into an image or scene to use as metadata.

Examples of information we know:

- Pop culture references
- Cartoons
- Anime
- Mythology
- etc.
