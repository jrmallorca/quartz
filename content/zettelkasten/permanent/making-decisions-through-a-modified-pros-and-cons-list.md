# Making decisions through a modified pros-and-cons list

According to [this article](https://time.com/3772262/billionaire-trick-for-decisions/), a billionaire called Seymour Schulich has modified the existing pros-and-cons list into a "Decision-Maker" for making decisions.

This tool can [[remove-emotion-from-decisions]], which is the reason for its efficacy.

The method is the following:

- List each **positive** argument and score them from 0 to 10.
- List each **negative** argument and score them from 0 to 10.
- Find the **sum** of _positive_ scores.
- Find the **sum** of _negative_ scores.
- If the _positive sum_ is **at least double** the _negative sum_, make the decision.
- Else, if the _positive sum_ is **higher than** the _negative sum_ but NOT **at least double** the value, think twice before doing it.
- Else, if the _positive sum_ is **lower than** the _negative sum_ don't make the decision.
