# Failure is a lesson, if not fatal

Failure, when not fatal, is not the end but a setback if the person learns/reflects from it. Failure is only the end if it is accepted as the end.

Failure is only really fatal when it involves significant harm, typically in the physical sense. While this may have been a prevalent problem pre-civilisation, fatal failure is rarely encountered.

Part of the [[organise-standardise-optimise]] process requires [[standardisation-before-optimisation]]. This standardisation often includes various wins and losses. All of these can be fed as input for [[reflection]] to improve.

If we do encounter a situation that presents the possibility of fatal failure, then practice of a similar but less high-stakes situation can improves our odds of not failing due to familiarity.
