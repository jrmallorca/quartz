# Size and simplicity of the system should determine monolithic or microservice architecture

[[monolithic-architecture]] is appropriate for small and simple applications or prototypes that only require a single code base. As specified in the [[deployment-process-between-monolithic-and-microservice-architecture]], the [[monolithic-architecture]] would make it easy to develop fast.

[[microservice-architecture]] would increase complexity of starting development which would be unnecessary for such simple applications. This architecture is more suitable for larger systems which can scale.
