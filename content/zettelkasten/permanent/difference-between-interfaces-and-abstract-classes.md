# Difference between interfaces and abstract classes

The difference between a [[java-interface]] and a [[jave-abstract-class]] is that:

- A [[java-interface]] represents a contract for classes to implement functionality.
- A [[java-abstract-class]] is like a [[java-interface]] that contains common functionality.
