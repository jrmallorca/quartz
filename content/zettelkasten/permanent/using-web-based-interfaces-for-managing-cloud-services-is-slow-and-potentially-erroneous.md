# Using web-based interfaces for managing cloud services is slow and potentially erroneous

Web-based interfaces for managing cloud services, such as [[zettelkasten/literature/aws-management-console]] and [[zettelkasten/literature/azure-resource-manager-arm]], are slow for dynamically managing cloud services and can introduce human error.

Instead, use the CLI equivalents such as [[zettelkasten/literature/microsoft-azure-cli]] or [[zettelkasten/literature/aws-cli]].
