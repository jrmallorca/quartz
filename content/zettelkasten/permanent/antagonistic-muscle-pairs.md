# Antagonistic muscle pairs

According to [this BBC bitesize guide](https://www.bbc.co.uk/bitesize/guides/zpkr82p/revision/4) antagonistic muscle pairs use [[muscle-contraction]] such that one muscle contracts to move a body part, then the other muscle contracts to return it to the original position.

There are [[antagonistic-muscle-pair-roles]] that allow for this to happen. This is an [[example-of-an-antagonistic-muscle-pair-in-action]].

The following is a [[table-of-antagonistic-muscle-pairs]].

Other muscles are also involved to assist antagonistic pairs to work efficiently. These are [[fixator-muscles]] and [[synergist-muscles]].
