# Elaborately encoded scenes should be vivid and multi-sensory

The scenes created from [[elaborative-encoding]] should be as vivid and as multi-sensory as possible. This will increase the memorability of the information we want to retain by turning it into a [[superstimulus]].

For each scene (metadata) we want to associate information with, try to include and/or exaggerate the following:

- Can we hear the scene?
- Can we feel the scene?
- Can we smell the scene?
- Can we taste the scene?
- Can the colours of the scene be more vivid/contrasting?
- Can we turn more ordinary objects in a scene into a rarer version? For example:
    - A purple candle instead of a cream candle.
    - A throne instead of a chair.
- Can the contents of the scene's size be bigger?
- Can we make the genre of the scene interesting? For example:
    - Violent.
    - Sexual.
    - Cute.
    - Disturbing.
    - Involves social/cultural references.
