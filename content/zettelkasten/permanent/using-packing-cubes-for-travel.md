# Using packing cubes for travel

Packing cubes are very useful as an organisation tool in bags.

Depending on the [[sorting-methods-for-contents-of-packing-cubes-for-travel]] used, they can make the following processes easier:
- Packing
- Unpacking
- Locating certain items
- Separating contents
    - Laundry and clean clothes
    - Wet and dry items
