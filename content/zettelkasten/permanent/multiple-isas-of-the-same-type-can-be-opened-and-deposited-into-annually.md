# Multiple ISAs of the same type can be opened and deposited into annually

As of April 2024, people will be able to open and deposit into multiple [[isa]]s of the same type annually (e.g., 2 S&S ISAs). That will replace current rules that only let you put money into one of each type of [[isa]] every tax year.
