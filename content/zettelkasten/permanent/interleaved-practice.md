# Interleaved practice

Interleaved practice is the practice of different topics, in a random order, within a learning session.

The key aspect to interleaved practice is that the learner doesn't know what problem they will encounter next.

## Concrete example

A mathematics student might practice addition, subtraction, multiplication, and division problems all within the same session and randomising the problems encountered, rather than practising only addition problems for a set period, then moving on to subtraction, and so on.
