# Atomic Habits

An atomic habit is a [[habit]] of relatively simple action that adheres to [[atomicity]].

This usually either serves as a [[gateway-habit]], a menial task that needs to be done to focus on more cognitively stimulating tasks, or a small addition to an existing routine.

As atomic habits are an easy gateway to success, it should help with the note [[habit-formation-minimises-cognitive-load-usage-for-other-activities]].
