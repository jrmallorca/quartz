# Private cloud benefits may not be as significant if hosted on premises

While [[cloud-computing-removes-some-IT-burden-from-company]], it may not be as significant if it is hosted on-premises as mentioned in [[private-cloud-can-be-hosted-either-on-premises-or-by-a-cloud-provider]].

## Flashcards

In a _PRIVATE cloud model_, would the **benefits of cloud computing be as significant** if hosted ON-PREMISES? :: No.

In a _PRIVATE cloud model_, would the **benefits of cloud computing be as significant** if hosted by a THIRD-PARTY provider? :: Yes.
