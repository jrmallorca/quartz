# Lombok `@Setter` annotation

The [[lombok]] `@Setter` annotation will generate the default setter for its respective annotated field.

For a field called `foo`, A default setter with 1 argument will be named `setFoo()` and returns void, where the argument provided will set the value of `foo`.
