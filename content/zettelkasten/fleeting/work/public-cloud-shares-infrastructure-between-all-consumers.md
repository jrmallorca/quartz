# Public cloud shares infrastructure between all consumers

In this model, the [[cloud-providers-already-have-infrastructure]] and the company uses the shared infrastructure from them which is accessible on a public network. This is how [[cloud-computing-removes-some-IT-burden-from-company]].

## Flashcards

In a _PUBLIC cloud model_, is the infrastructure **shared or not** between all consumers? :: Shared.

In a _PUBLIC cloud model_, are there likely to be  **multiple consumers or a single consumer**? :: Multiple.
