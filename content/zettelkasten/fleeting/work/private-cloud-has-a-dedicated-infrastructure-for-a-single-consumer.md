# Private cloud has a dedicated infrastructure for a single consumer

A [[private-cloud]] has a dedicated cloud infrastructure for a single consumer.

This is unlike [[public-cloud-shares-infrastructure-between-all-consumers]].

## Related content

- [Exam Ref AZ-900 Microsoft Azure Fundamentals](https://learning.oreilly.com/library/view/exam-ref-az-900/9780137955107/m01_ch01.xhtml)

## Flashcards

In a _PRIVATE cloud model_, is the infrastructure **shared or not** between many consumers? :: Not shared.

In a _PRIVATE cloud model_, are there likely to be  **multiple consumers or a single consumer**? :: Single.
