# Lombok `@Data` annotation

The [[lombok]] `@Data` annotation creates the following:

- [[lombok-required-args-constructor-annotation]],
- [[lombok-getter-annotation]] for all fields,
- [[lombok-setter-annotation]] for all fields,
- [[lombok-equals-and-hashcode-annotation]],
- [[lombok-to-string-annotation]].
