# Public cloud authorisation security measures may not be enough for company

Even if [[public-cloud-can-have-security-measures-for-authorisation]], it may not be enough to meet the company's security measurements. It would still be best to use a [[private-cloud]] as [[private-cloud-provides-privacy]].

Will _PUBLIC cloud model security measures_ **always** be enough to meet company security requirements? :: No.
