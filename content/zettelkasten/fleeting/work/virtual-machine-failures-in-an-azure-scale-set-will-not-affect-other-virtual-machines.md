# Virtual machine (VM) failures, in an Azure scale set, will not affect other virtual machines

If a running [[virtual-machine]] in an [[zettelkasten/fleeting/work/structure/azure-scale-set]] fails, such as these [[examples-of-failure-from-a-reliant-computer-system]], then the other [[virtual-machine]]s in [[azure-scale-sets-have-a-maximum-of-1000-virtual-machines]] will not be affected.

This maintains [[azure-scale-sets-allows-for-high-availability]].
