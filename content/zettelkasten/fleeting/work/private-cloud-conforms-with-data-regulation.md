# Private cloud conforms with data regulation

A [[private-cloud]] conforms with data regulation as [[private-cloud-provides-privacy]].

## Flashcards

What regulations do _PRIVATE cloud models_ **conform to** that PUBLIC cloud models cannot? :: Data regulation.

Why can _PRIVATE cloud models_ **conform to data regulation**? :: The data is private, only accessible by a single appropriate consumer.
