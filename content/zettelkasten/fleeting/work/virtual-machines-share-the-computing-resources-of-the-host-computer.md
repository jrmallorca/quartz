# Virtual machines share the computing resources of the host computer

As [[one-physical-computer-can-run-multiple-virtual-machines]], all [[virtual-machine]]s that come from the same host computer will share the computing resources of the host computer (i.e., CPU, GPU, memory, etc.). This is otherwise known as [[multitenancy]].
