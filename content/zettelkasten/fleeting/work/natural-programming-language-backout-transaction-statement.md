# Natural programming language BACKOUT TRANSACTION statement

[[zettelkasten/fleeting/work/structure/natural-programming-language]] has an `BACKOUT TRANSACTION` statement which cancels any of the related [[natural-programming-language-update-and-transaction-query-statements-to-adabas]].

Examples of cancelling the transactions are within [[natural-programming-language-update-and-transaction-query-statements-to-adabas]], just replacing any `end transaction` statement to `backout transaction`.
