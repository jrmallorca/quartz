# Phased approach of software testing and deployment

The phased approach consists of hosting an application within the following order of environments:

1. [[development-environment]]
2. [[testing-environment]]
3. [[acceptance-environment]]
4. [[production-environment]]

[[phased-approach-of-software-testing-and-deployment-minimises-risk-of-application-failure]].
