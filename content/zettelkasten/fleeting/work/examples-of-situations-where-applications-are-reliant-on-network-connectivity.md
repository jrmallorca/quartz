# Examples of situations where applications are reliant on network connectivity

- Users need connection to run the application.
- Calling required back-end systems such as database servers.
- Calling to other applications or APIs.

- [Exam Ref AZ-900 Microsoft Azure Fundamentals](https://learning.oreilly.com/library/view/exam-ref-az-900/9780137955107/m01_ch01.xhtml)

## Flashcards

Is an application _reliant on network connectivity_ if the **users must have an internet connection to run the application**? :: Yes.

Is an application _reliant on network connectivity_ if it needs to **call database servers**? :: Yes.

Is an application _reliant on network connectivity_ if it needs to **call other applications or APIs**? :: Yes.
