# Natural programming language comments

[[zettelkasten/fleeting/work/structure/natural-programming-language]] have the following comment rules:

When using an entire line as a comment, you can input any of the following at the start of the line:

- * some comment
- ** some comment
- /* some comment

When inputting comments at the latter end of a line, you can only use the following:

- some code /* some comment
