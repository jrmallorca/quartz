# Eggs do not need to be refrigerated if harvested from Europe

For countries that don't wash their eggs, like European countries, they don't need to be stored in the fridge. Eggs have a natural coating that can protect it from bacteria like salmonella.

Countries that do wash their eggs, like American countries, need to store eggs in the fridge as the coating is washed away.
