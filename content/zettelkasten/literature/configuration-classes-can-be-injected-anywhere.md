# `@Configuration` classes can be injected anywhere

[[spring-configuration-annotation]] classes can be injected anywhere. They don't have an order to apply in (e.g., the onion architecture of controller, service, and repository).

## Flashcards

Do _Spring `@Configuration` classes_ **follow onion architecture**? :: No. 

**Where** can _Spring `@Configuration` classes_ be INJECTED? :: Anywhere in the repository.
