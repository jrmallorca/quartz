# Shared responsibility model

The shared responsibility model describes how much of the responsibility is managed between the company and the [[zettelkasten/fleeting/work/structure/cloud-providers]], where the responsibility could be a web server, database server, IT department, etc. We can employ this as [[cloud-providers-already-have-infrastructure]].

Like with the [[consumption-based-model]], this is how [[cloud-computing-is-as-scalable-as-the-company-wants]] and how [[cloud-is-more-cost-effective-than-on-prem]].
