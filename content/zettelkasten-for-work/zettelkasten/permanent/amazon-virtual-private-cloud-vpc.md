# Amazon Virtual Private Cloud (VPC)

[[amazon-web-services]] Virtual [[private-cloud]] (VPC) is a networking service to establish boundaries around AWS resources.

Boundaries can be established by defining the private IP range for AWS resources, such as [[amazon-elastic-compute-cloud-ec2]] and [[aws-elastic-load-balancing-elb]], and place them inside the VPC.
