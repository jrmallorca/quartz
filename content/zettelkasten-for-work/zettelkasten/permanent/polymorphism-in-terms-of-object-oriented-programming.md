# Polymorphism, in terms of object-oriented programming

Polymorphism is the ability for something to be displayed in multiple forms. For example, a man can be a father, husband, and employee. Each role has different sets of behaviours, but all stems from the same person.

Typically, this is seen in [[function-overloading]], where a function can have multiple forms that, when called, have different results.
