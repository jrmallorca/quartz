# OpenAPI description file

The [[openapi-specification]] description is the file for our [[openapi-specification]].

[[openapi-descriptions-can-be-written-in-yaml-or-json]]. However, [[openapi-descriptions-should-be-written-in-yaml]].

The root of the document, is the [[openapi-object]]. Within it, we can [[define-api-endpoints-in-openapi-descriptions]] and [[define-reusable-components-in-openapi-descriptions]].
