# Application failure can cause a lack of availability

An application failure can cause a lack of availability. This is usually the result of a software bug or application design.

Ways to reduce this risk are:

- As [[cloud-providers-offers-different-environments-for-hosting-an-application]], a company can do a [[phased-approach-of-software-testing-and-deployment-minimises-risk-of-application-failure]].
- [[canary-testing-minimises-impact-of-application-failure]].
- [[rollback-to-prior-version-on-application-failure-to-minimise-lack-of-availability]].
