# AWS EC2 Storage optimized instance

Storage optimized [[amazon-elastic-compute-cloud-ec2]] instance types are ideal for high, sequential read/write access to large datasets on local storage:

- Distributed file systems,
- Data warehousing applications,
- High frequency online transaction processing (OLTP) systems.
