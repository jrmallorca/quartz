# Cloud providers can move applications to another host

In the event of a large geographical area, such as [[zettelkasten-for-work/zettelkasten/permanent/natural-disasters-can-affect-application-availability-and-data]] where [[power-outages-can-cause-a-lack-of-availability]], and [[cloud-providers-have-power-backups-and-redundancy-systems-to-minimise-impact-of-power-outages]] isn't enough, [[zettelkasten/fleeting/work/structure/cloud-providers]] can host the application to another region that isn't affected.

Though, even if it isn't a hybrid cloud, it may cause [[hybrid-cloud-may-experience-application-slowdowns-due-to-geographical-distances]]
