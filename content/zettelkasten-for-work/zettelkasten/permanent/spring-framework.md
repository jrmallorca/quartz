# Spring Framework

Spring framework is an ecosystem of frameworks comprised of:

- [[spring-core]]
- [[spring-model-view-controller]]
- [[spring-data-access]]
- [[spring-testing]]
- [[custom-exception-handling-in-java-spring]]

Spring is an application framework used to develop Java enterprise applications. It provides features such as dependency injection and modules such as Spring MVC and Spring Test. All of this can drastically reduce development time due to a reduction of boilerplate code to write as Spring handles it for us.
