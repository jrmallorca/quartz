# Network security group

A network security group is a virtual firewall that controls inbound and outbound traffic for a [[virtual-machine]].

## Analogy

Imagine you are in an apartment building with a door attendant who greets guests in the lobby. You can think of the guests as [[network-packet]]s and the door attendant as a security group. As guests arrive, the door attendant checks a list to ensure they can enter the building. However, the door attendant does not check the list again when guests are exiting the building
