# Data centres in availability zones have independent power, cooling, and networking infrastructure

Each data centre in a [[cloud-availability-zone]] has independent power, cooling, and networking infrastructure.

This helps to minimise [[common-issues-of-losing-application-and-data-availability]] within a [[cloud-region]] as [[cloud-regions-have-a-minimum-of-3-availability-zones]].
