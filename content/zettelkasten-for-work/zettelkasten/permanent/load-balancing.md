# Load balancing

Load balancing refers to distributing a set of tasks over a set of computing resources for efficient processing.

As an analogy, think of a retail worker trying to even out the queues for each cashier. That retail worker serves as the load balancer while the cashiers would likely be [[virtual-machine]]s.
