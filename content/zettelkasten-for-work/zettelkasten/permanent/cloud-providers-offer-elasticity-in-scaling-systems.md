# Cloud providers offer elasticity in scaling systems

[[zettelkasten/fleeting/work/structure/cloud-providers]] offer [[elasticity-of-scalability]] based on usage patterns of the application. For example, [[auto-scaling]] based on metrics such as CPU usage and memory usage, or on other metrics that are specific to the type of application.
