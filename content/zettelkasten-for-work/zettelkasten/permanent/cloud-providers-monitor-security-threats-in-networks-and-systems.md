# Cloud providers monitor security threats in networks and systems

To ensure [[cloud-providers-can-guarantee-a-certain-level-of-availability]], networks and systems are monitored to detect security threats and immediately eliminate them. This is a default benefit of using [[cloud-computing]] and likely does not need any action from us.

In the event that action does need to be taken from us, [[zettelkasten/fleeting/work/structure/cloud-providers]] will provide tools or resources to ease the difficulty of implementing them.
