# Application Insights service can diagnose problems

[[zettelkasten/fleeting/work/structure/cloud-providers]] can also provide tools to diagnose problems easier. [[zettelkasten/fleeting/work/structure/microsoft-azure]] provides a service called "Application Insights" to understand performance and reliability of the application by integrating itself with it.

This solves the problem of [[application-failure-can-cause-a-lack-of-availability]].
