# OpenAPI descriptions should be written in YAML

While [[openapi-descriptions-can-be-written-in-yaml-or-json]], YAML is preferred as that is the more human readable format.

YAML allows us to:

- write comments,
- and reference constant values at multiple places (helpful for DRY).
