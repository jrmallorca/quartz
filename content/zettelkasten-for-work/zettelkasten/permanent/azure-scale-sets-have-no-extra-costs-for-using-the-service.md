# Azure scale sets have no extra costs for using the service

The [[zettelkasten/fleeting/work/structure/azure-scale-set]] service has no extra costs of using it; the [[consumption-based-model-only-needs-payment-for-time-used-of-computing-resources]] only applies for the running [[virtual-machine]]s within the [[zettelkasten/fleeting/work/structure/azure-scale-set]].

Will using an **Azure scale set service** INCUR EXTRA COSTS? :: No.
