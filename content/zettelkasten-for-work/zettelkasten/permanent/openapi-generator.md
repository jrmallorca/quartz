# OpenAPI generator

The [[openapi-specification]] generator is a code generator that uses an [[openapi-description-file]] to generate any specified components and endpoints.

The OpenAPI generator has a [Maven plugin](https://github.com/OpenAPITools/openapi-generator/tree/master/modules/openapi-generator-maven-plugin).
