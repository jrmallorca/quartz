# AWS EC2 Accelerated computing instance

Memory optimized [[amazon-elastic-compute-cloud-ec2]] instance types are ideal for any tasks using hardware accelerators (e.g., GPUs, sound cards, etc.) to expedite data processing:

- Floating point number calculations,
- Graphics processing,
- Data pattern matching.
