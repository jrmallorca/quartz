# Creating a REST API in Java through a schema-first approach

To create a [[rest-api]] in Java through a [[schema-first-approach]]:

1. Create a Spring project through [[spring-initializr]].
2. Use the [Swagger Editor](https://editor.swagger.io/) to get a baseline [[openapi-description-file]] to modify for our API.
3. Copy-paste it into a YAML file under what's specified in [[maven-project-object-model-pom]], under the plugin's `<inputSpec>`.
    - This will likely be somewhere under `/src/main/resources`.
4. Generate the code for the API interfaces and models from the schema through the [[openapi-generator]].
5. Afterwards, implement the interfaces and create a REST API as you would.
6. (Optional) Once the schema is getting too big, or another feature is being added that should be separated to its own schema file, create a single [[openapi-description-file]] that [[define-reusable-components-in-openapi-descriptions]] to all our other [[openapi-description-file]]s to be referenced in our Maven.
