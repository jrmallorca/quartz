# Cloud region

A region is a set of data-centres deployed within a [[latency]]-defined perimeter and connected through a dedicated regional low-[[latency]] network.

Broken down, this sentence translates to the following:

- The data-centres are only a certain distance between each other to ensure time taken for data to travel is minimised (low-[[latency]]).
- The data centres are connected with fiber network connection.
