# ADABAS database descriptor

An [[zettelkasten/fleeting/work/structure/adabas-database]] descriptor is the name for a key/index of an ADABAS record. There are 5 different types of descriptors:

- Descriptor = Standard index for one elementary field or a field in a Multiple Value / Periodic Group.
- [[adabas-database-hyperdescriptor]]
- [[adabas-database-phonetic-descriptor]]
- [[adabas-database-subdescriptor]]
- [[adabas-database-superdescriptor]]
