# Cloud is more cost effective than on-prem

Often, Cloud is more cost effective than on-prem servers. This is largely because [[cloud-computing-is-as-scalable-as-the-company-wants]] as [[cloud-providers-already-have-infrastructure]], versus investing heavily in infrastructure, IT staff, etc.
