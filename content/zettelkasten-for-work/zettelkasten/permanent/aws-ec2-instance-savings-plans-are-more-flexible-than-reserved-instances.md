# AWS EC2 instance savings plans are more flexible than reserved instances

[[aws-ec2-instance-savings-plans]] are more flexible than [[aws-ec2-standard-reserved-instances-pricing]] or [[aws-ec2-convertible-reserved-instances-pricing]].

This is due to not needing to specify upfront of the EC2 instance type and size, OS, and tenancy for a discount, nor commit to a certain number of EC2 instances over a 1 year or 3 year term.

This is unlike anything mentioned in [[aws-ec2-standard-reserved-instances-are-less-flexible-than-convertible-reserved-instances]].
