# Format for conventional comments

> **\<label> (\<decorations>):** \<subject>
>
> \<discussion>

- `label` = Single label describing the type of comment it will be.
  - [[conventional-comment-labels]]
- `subject` = Main message of the comment.
- `decorations` (optional) = Extra decorating labels for the comment. They are surrounded by parentheses and comma-separated.
  - [[conventional-comment-decorations]]
- `discussion` (optional) = Supporting statements, context, reasoning, etc. to communicate the reason and possible solutions for the comment.

## Example

> **suggestion (non-blocking, ux):** This is not worded correctly.
>
> Can we change this to match the wording of the marketing page?
