# Sometimes convention is better than being correct

**Situation** - What was the situation/context?

While refactoring a program in DVLA, I came across a potential code smell. This was about creating an interface in java and only having 1 implementation with an -Impl suffix in Java.

**Task** - What was the task you had to deal with?

I had a ticket to refactor this existing PoC and I wanted to make sure of my knowledge with my tech lead of the code smell.

**Action** - What was the action you took?

I was informed that while I was correct, the average developer in our client's site would probably prefer having that in.

**Result** - What happened as a result of the action and what did you learn?

As the code smell was more about readability rather than performance, I agreed with my tech lead to leave it as it is.
