# AWS Elastic Beanstalk

[[amazon-web-services]] Elastic Beanstalk is a service to create [[amazon-elastic-compute-cloud-ec2]] environments with provided code and configuration. It deploys the resources necessary to perform:

- Adjust capacity, or default amount of [[amazon-elastic-compute-cloud-ec2]] instances without scaling.
- [[zettelkasten/fleeting/work/structure/load-balancing]]
- [[auto-scaling]]
- [[zettelkasten/permanent/cloud-providers-monitor-the-health-of-their-computing-resources]]
