# Garbage collection in computer science

Garbage collection is automatic memory management that reclaims memory allocated by the program but is no longer referenced.

This is an alternative to manual memory management such as in C.

## Analogy

## Concrete example

Java uses a garbage collector in the language, and as such does not need the methods from C to allocate and deallocate memory.
