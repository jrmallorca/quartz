# Habit - Specify versions in Maven properties

## [[cue-in-terms-of-habits|Cues]]

## [[response-in-terms-of-habits|Responses]]

1. In the [[maven-project-object-model-pom]], add `<properties>`.
2. Inside the `<properties>`, add your versions in the form of this example: `<my.version>1.1.2-SNAPSHOT</my.version>`.

### Concrete example

```xml
<properties>
<my.version>1.1.2-SNAPSHOT</my.version>
</properties>
```
