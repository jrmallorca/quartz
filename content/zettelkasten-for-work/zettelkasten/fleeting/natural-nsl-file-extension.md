# Natural .NSL file extension

.NSL file extensions indicate the contents are a [Local Data Area](https://documentation.softwareag.com/natux/9.3.1/en/webhelp/natux-webhelp/firststeps/fs-lda.htm?hi=local+locale+locally+data+area+areas)

These are comparable to class files in an OOP language.
