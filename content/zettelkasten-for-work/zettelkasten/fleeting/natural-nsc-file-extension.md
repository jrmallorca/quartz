# Natural .NSC file extension

.NSC file extensions indicate the contents are a [Copycode](https://documentation.softwareag.com/natux/9.3.1/en/webhelp/natux-webhelp/pg/pg_obj_copycode.htm?hi=copycode+copycodes)

It resembles Dart's [part of](https://stackoverflow.com/questions/27763378/when-to-use-part-part-of-versus-import-export-in-dart) statement. This allows you to split code/libraries into multiple files.

It might also be comparable to a static method in an OOP language to expedite a process to another file.
