# Natural .NSM file extension

.NSM file extensions indicate the contents are a [map](https://documentation.softwareag.com/natux/9.3.1/en/webhelp/natux-webhelp/pg/pg_obj_map.htm?hi=map+maps+mapped+mapping)

This is the structure of the output. Take a look at HKOEQ01M.NSM where it outputs a confirmation page of permanently deleting all records for a Sales key.
