# Natural .NSG file extension

.NSG file extensions indicate the contents are a [Global Data Area](https://documentation.softwareag.com/natux/9.3.1/en/webhelp/natux-webhelp/firststeps/fs-gda.htm?hi=global+globals+globally+data+area+areas)

These may be comparable to class files in an OOP language, like [[natural-nsl-file-extension]], but globally used.
