# Natural .NSD file extension

.NSD file extensions indicate the contents are a [Data Definition Module (DDM)](https://documentation.softwareag.com/natux/9.3.1/en/webhelp/natux-webhelp/pg/pg_obj_ddm.htm?hi=data+definition+definite+definitions+module+modules)

These are likely the database files.
